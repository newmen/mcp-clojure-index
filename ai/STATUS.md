# Status of tasks from PLAN.md

1. **Completed** – The architecture was designed and refined: 7 modules + config, unified data models (CodeChunk, SymbolRecord, Edge, ParseResult, and others), complete interfaces (including find-by-protocol / find-by-record), an acyclic DAG dependency graph, PlantUML C4 diagrams (context + components), extensibility protocols (EmbeddingProvider, VectorStore, SymbolIndexProvider, GraphProvider), a test plan, and Kilo configuration.
2. **Completed** – The `mcp.parser` module was implemented: parsing of .clj/.cljc/.cljs/.edn files, extraction of top-level forms (defn, defn-, defmacro, defprotocol, defrecord, deftype, def, defonce, ns) with type, name, visibility, line coordinates (start_line / end_line), a SHA-256 hash of the content, and the full source text. Support for `^:dynamic` and reader metadata. The `mcp.config` module: loading and validation of config.edn with defaults. 23 unit tests in `test/mcp/parser_test.clj` and `test/mcp/fixtures/`, all pass (0 failures, 0 errors).
3. **Completed** – Semantic chunking of code based on the CST (rewrite-clj zipper API). The `mcp.parser` module was switched from the line-based parser to rewrite-clj with position tracking. Each semantic chunk corresponds to one top-level form (defn, defn-, defmacro, defprotocol, defrecord, deftype, def, defonce, ns). For each chunk the following is stored: the full source text, the definition type, the name, the file, the line range, and a SHA-256 hash of the content. The chunks do not overlap. EDN files are supported through top-level map/vector/set forms. Syntax errors are handled without interruption — a ParseError with an empty chunk list is returned. 5 new unit tests (chunks-do-not, chunks-contain-full-source, chunks-have-no-nested-overlap, edn-file-line-numbers, hash-is-stable-across-parses). 28 tests, 83 assertions — all pass (0 failures, 0 errors).
4. **Completed** – The `mcp.symbol-index` module was created (`src/mcp/symbol_index.clj`) — a symbol index with the functions `build-index`, `find-symbol`, `find-namespace`, `find-by-type`, `find-by-protocol`, `find-by-record`, `remove-file!`, `add-file!`. The index is built across 5 dimensions: by-qname, by-simple, by-file, by-type, namespaces. The parser was extended: metadata extraction (docstring, arglists, tag) through the node API, whitespace-node filtering, reader metadata support, and extraction of symbols referenced in a body. Added the `enrich-project-chunks` helper to enrich the results of `parse-project` with a namespace. Fixed of-form name extraction with trailing delimiters. 33 unit tests — 77 tests, 199 assertions total.
5. **Completed** – The `mcp.graph` module was implemented (`src/mcp/graph.clj`) — a dependency graph with the functions `build-graph`, `find-callers`, `find-callees`, `find-edges-by-chunk`, `remove-file!`, `add-file!`. Each graph vertex is mapped to a Qdrant record through `chunk-id` (UUID). The graph is built from the referenced symbols, resolving them through the SymbolIndex by 3 strategies: direct qualified lookup, namespaced symbols, simple names. Self-loops and special operators are excluded. Incremental update is supported. 27 unit tests in `graph_test.clj` + a `graph_project/` fixture. 104 tests total.
6. **Completed** – The `mcp.embeddings` module was implemented (`src/mcp/embeddings.clj`): `build-embedding-text` (builds the text from CodeChunk without extra blank lines), `generate` (a single-argument interface through `*config*`), `generate-from-chunks` (with skip via the hash cache), an on-disk EDN cache with atomic writes, and `rerank` with fallback on network errors. 24 unit tests, 0 failures, 0 errors, 0 reflection warnings.
7. **Completed** – The `mcp.qdrant` module (`src/mcp/qdrant.clj`) — the storage layer in Qdrant via HTTP REST: `create-collection!` (768-dim, Cosine), `upsert!` (batches of 100), `delete!` (by file filter), `search`, `collection-exists?`. The payload of each chunk has 11 fields (id, type, language, namespace, symbol, type, visibility, file, start_line, end_line, hash). The embedding is stored as a Qdrant vector, not in the payload. 16 unit tests, 140 tests total.
8. **Completed** – The `mcp.watcher` module (`src/mcp/watcher.clj`) — incremental indexing through Java WatchService: `start-watching!` / `stop-watching!`, `process-modify`, `process-delete`, `process-rename` (hash comparison), debounce with a 150ms window, `reindex-all!`, `update-file-path!`. 160 tests, 423 assertions.
9. **Completed** – The `mcp.search` module (`src/mcp/search.clj`) — hybrid search combining vector search, Cross Encoder reranking, and optional expansion via the symbol index and graph: `search`, `search-simple`, `search-full`. 19 unit tests, 179 tests total.
10. **Completed** – The MCP server was implemented (JSON-RPC 2.0, STDIO). The `mcp.tools` module has 8 tools with JSON Schema. The `mcp.server` module has `start` and `stop`, method handling, and graceful shutdown. 38 unit tests, 220 total.
11. **Completed** – Index state recovery from Qdrant on restart: `collection-info` and `scroll-all` in `mcp.qdrant`, and `restore-state!` in `mcp.watcher` (checks the recreate flag, scrolls, restores SymbolIndex/Graph, syncs changed/new/deleted files, falls back to full `reindex-all!`). 4 new tests, 223 total.
12. **Completed** – Integration with Kilo Code: the `clojure-code-index` server in the global `kilo.json` with a configuration. 222 tests, linter clean.
13. **Completed** – Testing and optimization: created the `large_file.clj` fixture (10565 lines), added edge-case tests to all modules, and created `performance_test.clj` (parsing < 5s, index < 3s, graph < 5s, pipeline < 15s). 313 tests, 3013 assertions.
14. **Completed** – Automatic determination of `:index/root-path` and `:qdrant/collection` from the environment: `mcp.config/resolve-config` with the chain config.edn → `QD_PROJECT_ROOT` → `VSCODE_CWD` → `user.dir`; the collection is computed from the last path segment with a `-collection` suffix; `:embedding/cache-dir` is computed as `<root-path>/.mcp/embedding-cache`. 8 unit tests, 323 total.
