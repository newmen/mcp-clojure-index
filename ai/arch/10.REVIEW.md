## Strengths of the architecture

1. **Strict DAG without cycles** — 6 topological layers (layer 0–5), dependencies only top-down
2. **Extensibility protocols** — `EmbeddingProvider`, `VectorStore`, `SymbolIndexProvider`, `GraphProvider` allow replacing any component without changing the calling code
3. **Rename as a single event** — debounce ~100ms merges DELETE+CREATE, hash check determines full reindex vs path update
4. **Link of the graph to Qdrant via chunk-id** — the graph is decoupled from the payload but unambiguously matched through `:edge/from-id` / `:edge/to-id`
5. **Unified data models** — `CodeChunk`, `SymbolRecord`, `Edge`, `ParseResult` cover all fields from every task
