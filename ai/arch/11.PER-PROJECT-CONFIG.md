# Per-project configuration

## Motivation

The MCP server is registered once in the global Kilo Code configuration. It must be able to index **any Clojure project** without changing the server or Kilo Code configuration.

Current problem:
- `:index/root-path` is hardcoded in `config.edn`, which lies in the MCP server repository.
- When switching to another project, the global `kilo.jsonc` or `config.edn` must be changed.
- The embedding cache is shared across all projects (leads to hash collisions of different code-bases).

## Solution

### The only per-project parameter: the Qdrant collection name

Each project uses **its own collection** in Qdrant. The collection name is computed automatically from the project root, but can be overridden.

### Computed parameters

| Parameter | Source | Example |
|-----------|--------|--------|
| `:index/root-path` | `VSCODE_CWD` (env) or `user.dir` (system property) | `/Users/altermn/projects/my-clojure-app` |
| `:qdrant/collection` | `(str (last-segment root-path) "-collection")` | `my-clojure-app-collection` |
| `:embedding/cache-dir` | `(str root-path "/.mcp/embedding-cache")` | `/Users/altermn/projects/my-clojure-app/.mcp/embedding-cache` |

### Resolution rules (chain of responsibility)

Each parameter is resolved along the chain:

```
:index/root-path
  1. Explicit in config.edn → used as is
  2. QD_PROJECT_ROOT (env) → used
  3. VSCODE_CWD (env) → used
  4. user.dir (System/getProperty) → used
  5. Default: "."

:qdrant/collection
  1. Explicit in config.edn → used as is
  2. QD_COLLECTION (env) → used
  3. (str (last-segment root-path) "-collection") → computed
  4. Default: "clojure-code-index"

:embedding/cache-dir
  1. Explicit in config.edn → used as is
  2. (str root-path "/.mcp/embedding-cache") → computed
  3. Default: ".mcp/embedding-cache"
```

### Running in different environments

#### VSCode + Kilo Code (main scenario)

Kilo Code receives a `VSCODE_CWD` from VSCode — this is the root of the opened workspace. The MCP server starts with `workingDirectory` pointing at the server itself, but reads `VSCODE_CWD` to determine the indexed project.

Global Kilo Code configuration (once):
```json
{
  "mcp": {
    "clojure-code-index": {
      "type": "local",
      "command": ["lein", "run"],
      "args": ["resources/config.edn"],
      "workingDirectory": "/Users/altermn/projects/clojure/mcp",
      "enabled": true
    }
  }
}
```

None of the projects require local configuration. When opening any Clojure project in VSCode, the MCP server automatically detects its root via `VSCODE_CWD` and creates/uses the `<project-name>-collection` collection in Qdrant.

#### Outside VSCode (CLI, REPL)

```bash
# root-path from user.dir (current directory)
lein run resources/config.edn

# force root-path
QD_PROJECT_ROOT=/path/to/project lein run resources/config.edn

# force collection
QD_COLLECTION=my-project-custom lein run resources/config.edn
```

### Configuration resolution flow

```
config.edn (reading a file)
    │
    ▼
load-config → raw config map (merge defaults + file overrides)
    │
    ▼
resolve-config → redefinition of root-path, collection, cache-dir
    │
    ▼
validate-config → check required fields
    │
    ▼
Ready Config → mcp.server/start
```

### Changes in the modules

#### `mcp.config` — adding the `resolve-config` function

```clojure
(defn resolve-config
  "Resolve computed config fields by applying the priority chain.
   Must be called after load-config."
  [cfg]
  (let [root-path (or (:index/root-path cfg)
                      (System/getenv "QD_PROJECT_ROOT")
                      (System/getenv "VSCODE_CWD")
                      (System/getProperty "user.dir")
                      ".")
        norm-root (s/replace root-path #"/$" "")
        collection (or (:qdrant/collection cfg)
                       (System/getenv "QD_COLLECTION")
                       (str (last (s/split norm-root #"/")) "-collection")
                       "clojure-code-index")
        cache-dir (or (:embedding/cache-dir cfg)
                      (str norm-root "/.mcp/embedding-cache"))]
    (assoc cfg
      :index/root-path norm-root
      :qdrant/collection collection
      :embedding/cache-dir cache-dir)))
```

#### `mcp.server` — adding a call to `resolve-config`

```clojure
(defn -main
  [& args]
  (let [config-path (or (first args) "resources/config.edn")
        cfg (-> (config/load-config config-path)
                (config/resolve-config)
                (config/validate-config))]
    (start cfg)))
```

### Reverse compatibility

- The old scenario with `config.edn` explicitly setting `:index/root-path` continues to work — the explicit value has the highest priority.
- The old scenario with `:embedding/cache-dir` in `config.edn` continues to work.
- If `VSCODE_CWD` is not set, the fallback to `user.dir` (current directory) — the same behavior as now.
