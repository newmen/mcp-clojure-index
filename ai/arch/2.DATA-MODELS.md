# Data models

All data models — plain Clojure maps with the following keys:

## `CodeChunk` — semantic chunk of code

```clojure
{:chunk/id        uuid
 :chunk/ns        "user.core"               ;; namespace — string representation of the ns
 :chunk/file      "/path/to/file.clj"       ;; absolute path
 :chunk/type      :fn                       ;; :fn — defn, defn-
                                           ;; :macro — defmacro
                                           ;; :protocol — defprotocol
                                           ;; :record — defrecord, deftype
                                           ;; :ns — ns form
                                           ;; :val — def (top-level constant/variable)
                                           ;; :top-level — a top-level s-expression that
                                           ;;              does not match other types
 :chunk/name      "my-func"                 ;; symbol name
 :chunk/source    "(defn my-func [x] ...)"  ;; source code
 :chunk/start-line 10                       ;; starting line in the file
 :chunk/end-line   25                       ;; ending line in the file
 :chunk/visibility :public                  ;; :public — defn, :private — defn-
 :chunk/language  "clojure"                 ;; "clojure" | "clojurescript" | "edn"
 :chunk/metadata  {:doc "..." :arglists [...] :tag :int}  ;; metadata from defn
 :chunk/symbols   #{'my-func 'other-func}   ;; all symbols mentioned in the body
 :chunk/hash      "6d0b9d7..."              ;; SHA-256 hash of the content for incremental indexing
 :chunk/file-hash "e3b0c442..."             ;; SHA-256 hash of the entire file (for restart and rename comparison)
 :chunk/embedding [0.1 -0.2 ...]}           ;; embedding vector (optional)
```

## `SymbolRecord` — a record in the symbol index

```clojure
{:sym/name       'user.core/my-func          ;; fully qualified name
 :sym/simple     'my-func                    ;; short name
 :sym/ns         'user.core                  ;; namespace
 :sym/type       :fn                         ;; :fn — defn, defn-
                                             ;; :macro — defmacro
                                             ;; :protocol — defprotocol
                                             ;; :record — defrecord, deftype
                                             ;; :val — def (top-level constant/variable)
                                             ;; :multimethod — defmulti, defmethod
 :sym/file       "/path/to/file.clj"
 :sym/line       10
 :sym/arglists   '([x y] [x])                ;; for functions/macros
 :sym/doc        "Returns the result of ..."
 :sym/protocol   'user.core/MyProtocol       ;; for protocol methods
 :sym/record     'user.core/MyRecord         ;; for records
 :sym/tag        :int                        ;; hint type
 :sym/chunk-id    uuid                       ;; reference to CodeChunk
 :sym/visibility :public                     ;; :public | :private
 :sym/aliases     #{'core/my-func}           ;; alternate names (via :refer :all)
```

## `Edge` — graph edge (call/dependency graph)

```clojure
{:edge/from     'user.core/my-func           ;; caller
 :edge/from-id  uuid                         ;; chunk-id of the caller (for linking to Qdrant)
 :edge/to       'user.lib/other-func         ;; callee
 :edge/to-id    uuid                         ;; chunk-id of the callee (for linking to Qdrant)
 :edge/type     :call                        ;; :call — function call in a body
                                           ;; :extend — protocol extension (extend-type, extend-protocol)
                                           ;; :implement — protocol implementation in deftype/defrecord
                                           ;; :require — require dependency in a ns form
                                           ;; :use — use dependency in a ns form
 :edge/file    "/path/to/file.clj"
 :edge/line    42}
```

## `NamespaceRecord` — namespace record

```clojure
{:ns/name       'user.core
 :ns/file       "/path/to/file.clj"
 :ns/requires   '[[clojure.string :as str]
                  [user.lib :refer [helper]]]
 :ns/imports    '[java.util.Date]
 :ns/provides   #{'user.core/my-func 'user.core/my-macro}}
```

## `EmbeddingInput` — text passed to the embedding model

```clojure
{:input/namespace  "bank.user"              ;; symbol namespace
 :input/symbol     "create-user"            ;; symbol name
 :input/docstring  "Creates a customer..."  ;; docstring (may be nil)
 :input/code       "(defn create-user ...)"  ;; source code of the definition
 :input/text       "Namespace:\nbank.user\n\nSymbol:\ncreate-user\n\nDocstring:\n...\n\nCode:\n(defn create-user ...)"}
```

## `SearchResult` — search result

```clojure
{:result/chunk    CodeChunk
 :result/score    0.92                       ;; cosine distance (similarity)
 :result/rank     1
 :result/re-rank  0.87}                      ;; reranker score
```

## `IndexStats` — index statistics

```clojure
{:index/files  150
 :index/chunks 2400
 :index/symbols 8500
 :index/namespaces 45
 :index/edges  12000
 :index/updated "2026-07-24T11:00:00Z"}
```

## `ParseResult` — parsing result for a file

```clojure
{:result/chunks [CodeChunk ...]              ;; successfully extracted chunks
 :result/errors [ParseError ...]}            ;; errors (if any)
```

## `ParseError` — parsing error for a single file

```clojure
{:error/file    "/path/to/file.clj"
 :error/line    42                           ;; line where the error occurred (may be nil)
 :error/column  10                           ;; column (may be nil)
 :error/message "Unmatched delimiter"}
```

## `Config` — configuration

```clojure
{:qdrant/host       "localhost"
 :qdrant/port       6333
 :qdrant/collection "mcp-project-collection"   ;; computed from root-path by default
 :qdrant/recreate?  false
 :ollama/url        "http://localhost:11434/v1"
 :ollama/embedding-model "vishalraj/nomic-embed-code"
 :ollama/reranker-model  "qllama/bce-reranker-base_v1"
 :embedding/cache-dir  ".mcp/embedding-cache"  ;; <root-path>/.mcp/embedding-cache by default
 :server/transport     :stdio
 :server/port          8080
 :index/root-path      "/path/to/project"     ;; from the environment by default (VSCODE_CWD / user.dir)
 :index/include-extensions [".clj" ".cljc" ".cljs" ".edn"]
 :index/exclude        ["target" ".git" ".lsp" ".clj-kondo" ".calva" ".kilo" ".mcp"]
 :search/top-k         100
 :search/re-rank-top   10}
```

**Value resolution rules (priority: highest → lowest):**

| Field | 1st priority | 2nd priority | 3rd priority | 4th priority |
|-------|--------------|--------------|--------------|--------------|
| `:index/root-path` | explicit in `config.edn` | `QD_PROJECT_ROOT` env | `VSCODE_CWD` env | `user.dir` system property |
| `:qdrant/collection` | explicit in `config.edn` | `QD_COLLECTION` env | `(str (last-segment root-path) "-collection")` | — |
| `:embedding/cache-dir` | explicit in `config.edn` | `(str root-path "/.mcp/embedding-cache")` | — | — |

The resolution rules are implemented in `mcp.config/resolve-config` — a function that takes the result of `load-config` and overrides/updates fields according to the described rules.
