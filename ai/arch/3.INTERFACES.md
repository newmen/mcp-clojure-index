# Module interfaces

## `mcp.parser/parse-file` — parsing a single file

```clojure
(parse-file file-path)
  ;; Input:  string — absolute path to a .clj/.cljc/.cljs/.edn file
  ;; Output: ParseResult {:chunks [CodeChunk ...] :errors [ParseError ...]}
  ;; Side effects: none (pure function)
```

## `mcp.parser/parse-project` — parsing the whole project

```clojure
(parse-project root-path exclude-regexes)
  ;; Input:  string, seq of regex
  ;; Output: {:chunks [CodeChunk ...]
  ;;          :errors [ParseError ...]}
  ;; Side effects: FS traversal
  ;; Note: symbols and namespaces are extracted separately through
  ;;   enrich-project-chunks, extract-symbols, chunk->symbol-record
```

## `mcp.symbol-index/build-index` — building the symbol index

```clojure
(build-index symbols)
  ;; Input:  seq of SymbolRecord
  ;; Output: SymbolIndex (map for fast lookup)
```

## `mcp.symbol-index/find-symbol` — search for a symbol by name

```clojure
(find-symbol index name)
  ;; Input:  SymbolIndex, string (validates the symbol by qualified or simple name)
  ;; Output: seq of SymbolRecord (nil if not found)
```

For the `SymbolIndex` arg, pass the whole map; for the name — either the qualified form (user.my/x) or the short form (x). By a qualified name returns the records whose `:sym/name` matches. By a short name — the records whose `:sym/simple` matches, sorted alphabetically.

## `mcp.symbol-index/find-namespace` — search for a namespace

```clojure
(find-namespace namespaces ns-name)
  ;; Input:  map ns-name → NamespaceRecord, string
  ;; Output: NamespaceRecord (nil if not found)
```

## `mcp.symbol-index/find-by-type` — search by symbol type

```clojure
(find-by-type index type)
  ;; type: :fn | :macro | :protocol | :record | :val | :multimethod
  ;; Output: seq of SymbolRecord
```

## `mcp.symbol-index/find-by-protocol` — search symbols by protocol name

```clojure
(find-by-protocol index protocol-name)
  ;; Input:  SymbolIndex, symbol (qualified or simple)
  ;; Output: seq of SymbolRecord (protocol methods)
```

## `mcp.symbol-index/find-by-record` — search symbols by record name

```clojure
(find-by-record index record-name)
  ;; Input:  SymbolIndex, symbol (qualified or simple)
  ;; Output: seq of SymbolRecord (record methods)
```

## `mcp.symbol-index/remove-file!` — remove a file's symbols from the index

```clojure
(remove-file! index file-path)
  ;; Input:  SymbolIndex, string — absolute path to the file
  ;; Output: SymbolIndex (updated, without the symbols of the removed file)
  ;; Side effects: none (pure function, returns a new index)
```

## `mcp.symbol-index/add-file!` — add/update a file's symbols in the index

```clojure
(add-file! index symbols)
  ;; Input:  SymbolIndex, seq of SymbolRecord — new symbols of the file
  ;; Output: SymbolIndex (updated, with added/replaced symbols)
  ;; Side effects: none (pure function, returns a new index)
```

## `mcp.graph/build-graph` — building the call graph

```clojure
(build-graph chunks index)
  ;; Input:  seq of CodeChunk, SymbolIndex
  ;; Output: {:edges [Edge ...]
  ;;          :callers {fn → [fn ...]}
  ;;          :callees  {fn → [fn ...]}}
```

## `mcp.graph/find-callers` — who calls a symbol

```clojure
(find-callers graph symbol)
  ;; Output: seq of Edge, sorted by name
```

## `mcp.graph/find-callees` — whom a symbol calls

```clojure
(find-callees graph symbol)
  ;; Output: seq of Edge, sorted by name
```

## `mcp.graph/remove-file!` — remove a file's edges from the graph

```clojure
(remove-file! graph file-path)
  ;; Input:  GraphResult, string — absolute path to the file
  ;; Output: GraphResult (updated, without the edges belonging to the removed file)
  ;; Side effects: none (pure function, returns a new graph)
```

## `mcp.graph/add-file!` — add/update a file's edges in the graph

```clojure
(add-file! graph edges)
  ;; Input:  GraphResult, seq of Edge
  ;; Output: GraphResult (updated, with added/replaced edges)
  ;; Side effects: none (pure function, returns a new graph)
```

## `mcp.embeddings/generate` — generate an embedding

```clojure
(generate texts)
  ;; Input:  seq of strings
  ;; Output: seq of number vectors (embeddings)
  ;; Side effects: HTTP request to Ollama
```

## `mcp.embeddings/rerank` — rerank the results

```clojure
(rerank query candidates)
  ;; Input:  query string, seq of {:text string :score number}
  ;; Output: seq of {:text string :score number :re-rank number}
  ;; Side effects: HTTP request to Ollama
```

## `mcp.qdrant/delete!` — delete chunks by file

## `mcp.qdrant/search` — search by embedding

```clojure
(search config embedding top-k)

  ;; Side effects: HTTP request to Qdrant
```

## `mcp.qdrant/collection-info` — collection info

```clojure
(collection-info config)
  ;; Input:  Config
  ;; Output: {:points-count int} or nil (collection does not exist)
  ;; Side effects: HTTP request to Qdrant
```

## `mcp.qdrant/scroll-all` — read all points of the collection

```clojure
(scroll-all config)
  ;; Input:  Config
  ;; Output: seq of CodeChunk (recovered from the payload of each point)
  ;;         or nil on error
  ;; Side effects: HTTP request to Qdrant (scroll with pagination by 100 points)
  ;; Note: embedding vectors are not requested (with_vector=false)
```

## `mcp.watcher/start-watching!` — start change tracking

```clojure
(start-watching! cfg index-ref graph-ref)
  ;; Input: Config, atom with SymbolIndex, atom with GraphResult
  ;; Output: {:watcher WatchService :stop-atom (atom nil)}
  ;; Side effects: registering WatchService on the project directories,
  ;;   dispatching parse-file / delete! / generate / upsert! on changes,
  ;;   updating the symbol index and dependency graph for the affected files,
  ;;   starting a background thread
```

## `mcp.watcher/stop-watching!` — stop change tracking

```clojure
(stop-watching! watcher)
  ;; Input: result of start-watching!
  ;; Output: nil
  ;; Side effects: closing WatchService, stopping the background thread
```

## `mcp.search/search` — hybrid search

```clojure
(search cfg query index graph chunk-map)
  ;; Input:  Config, query string, SymbolIndex (optional), GraphResult (optional),
  ;;        chunk-map (optional)
  ;; Output: vector of SearchResult {:result/chunk :result/score :result/rank :result/re-rank}
  ;;         or nil on an empty query
  ;; Side effects: HTTP request to Ollama (generate + rerank), HTTP request to Qdrant (search)
```

## `mcp.search/search-simple` — simplified search without expansion

```clojure
(search-simple cfg query)
  ;; Input:  Config, string
  ;; Output: seq of {:chunk CodeChunk :score number :re-rank number} or nil
  ;; Side effects: HTTP request to Ollama, HTTP request to Qdrant
```

## `mcp.search/search-full` — full search with chunk-map building

```clojure
(search-full cfg query index graph)
  ;; Input:  Config, string, SymbolIndex, GraphResult
  ;; Output: vector of SearchResult
  ;; Side effects: HTTP request to Ollama, HTTP request to Qdrant
```

  ;; Input:  state map

## `mcp.tools/handle-tool` — invoke an MCP tool

```clojure
(handle-tool tool-name args state)
  ;; Input:  string (tool name), map (arguments), state map
  ;; Output: {:content [{:type "text" :text "..."}]}
  ;; Side effects: call search/symbol-index/graph
```
