# Extensibility and component replacement

## Principle

The system uses Clojure protocols (`defprotocol`) for key extension points, enabling implementations to be replaced without changing the code of the calling modules.

## Protocols

### EmbeddingProvider — replacing the embedding model

```clojure
(defprotocol EmbeddingProvider
  (generate [this texts] "Text → vector(s)")
  (rerank [this query candidates] "Rerank the results"))
```

Implementations:
- `OllamaEmbeddingProvider` — uses the Ollama REST API
- `OpenAIEmbeddingProvider` — uses the OpenAI API
- `LocalEmbeddingProvider` — uses a local library

### VectorStore — replacing the vector store

```clojure
(defprotocol VectorStore
  (create-collection! [this config])
  (upsert! [this config chunks embeddings])
  (delete! [this config file-path])
  (search [this config embedding top-k]))
```

Implementations:
- `QdrantStore` — uses the Qdrant HTTP/gRPC API
- `MilvusStore` — uses Milvus
- `InMemoryStore` — in-memory for tests

### SymbolIndexProvider — replacing the symbol index

```clojure
(defprotocol SymbolIndexProvider
  (build-index [this symbols] "seq of SymbolRecord → SymbolIndex")
  (find-symbol [this index name] "SymbolIndex, symbol → seq of SymbolRecord")
  (find-namespace [this namespaces ns-name] "map, ns → NamespaceRecord")
  (find-by-type [this index type] "SymbolIndex, keyword → seq of SymbolRecord")
  (find-by-protocol [this index protocol-name] "SymbolIndex, symbol → seq of SymbolRecord")
  (find-by-record [this index record-name] "SymbolIndex, symbol → seq of SymbolRecord"))
```

Implementations:
- `DefaultSymbolIndex` — in-memory Clojure map (the main implementation)
- `PersistentSymbolIndex` — saves the index to disk (optional)
- `RecoveredSymbolIndex` — restores the index from Qdrant (scroll payload) at server start

### GraphProvider — replacing the dependency graph

```clojure
(defprotocol GraphProvider
  (build-graph [this chunks index] "seq of CodeChunk, SymbolIndex → GraphResult")
  (find-callers [this graph symbol] "Graph, symbol → seq of Edge")
  (find-callees [this graph symbol] "Graph, symbol → seq of Edge"))
```

Implementations:
- `LoomGraphProvider` — uses loom (main)
- `InMemoryGraphProvider` — a simple in-memory implementation for tests

## Config-driven choice of implementation

The implementation is specified in `config.edn`:

```clojure
{:embedding/provider     :ollama      ;; :ollama | :openai | :local
  :qdrant/provider       :qdrant      ;; :qdrant | :milvus | :in-memory
  :symbol-index/provider :default     ;; :default | :persistent
  :graph/provider        :loom        ;; :loom | :in-memory
  ...}
```

The implementation is loaded in `mcp.server/start` through a multimethod:

```clojure
(defmulti make-embedding-provider :embedding/provider)
(defmethod make-embedding-provider :ollama [config]
  (->OllamaEmbeddingProvider (:ollama/url config)))

;; config — is the parsed map from config.edn.
;; Loading from the file is done in mcp.server/start through mcp.config/load-config:
```

## Adding a new MCP tool

1. Write a function in `mcp.tools` that calls the necessary modules
2. Register it in `register!` using `defmethod` or a registration table

No other modules need to be changed.
