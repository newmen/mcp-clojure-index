# Task 1. Architecture design

## Description

At this stage the architecture of the whole system is designed, the main components, their areas of responsibility, and interaction methods are defined. Independent modules should be identified: a parser, an indexer, an embedding generator, a storage module, a search module, and an MCP server. Unified data models used across all components must be defined. The ability to independently replace embedding models, rerankers, and vector databases should be provided. The architecture is recommended to be built as a set of independent Clojure namespaces with minimal coupling between them.

### Tools

- Clojure
- rewrite-clj

### Input

None.

## Output

The designed project structure and a description of the interaction of all components in the /Users/altermn/projects/clojure/mcp/ai/arch directory. The dependencies between files/modules/namespaces are presented as a PlantUML C4 diagram.

### Acceptance criteria

- all main modules are defined;
- no cyclic dependencies;
- each component has a single responsibility;
- interfaces between components are defined.
