# Task 2. Implementing the Clojure parser

## Description

It is necessary to implement a source code reader module based on `rewrite-clj`. The parser must correctly handle all language constructs, including `defn`, `defmacro`, `defrecord`, `defprotocol`, `deftype`, `ns`, reader macros, metadata, and comments. The result must be a Concrete Syntax Tree (CST) that preserves the original file structure without loss of information. The parser must not modify the source code and must correctly handle syntax errors without interrupting the indexing of the rest of the project. In addition to building the CST, information about the location of each node in the source file (line number and column) must be extracted, since this data is used when forming the metadata for the index. The obtained coordinates must accompany each tree node up to the stage of forming semantic chunks.

### Tools

- rewrite-clj

### Input

A `.clj`, `.cljc`, `.cljs`, or `.edn` file obtained when traversing the file system.

### Output

A Concrete Syntax Tree containing the coordinates of all syntax nodes.

### Acceptance criteria

- all valid files are successfully parsed;
- parse errors are localized;
- the tree structure corresponds to the source code;
- the coordinates of all nodes are preserved;
- the obtained information is sufficient for subsequent determination of line ranges of each definition.
