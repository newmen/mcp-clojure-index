# Task 9. Implementing hybrid search

## Description

Combine several search mechanisms. Semantic search is performed through Qdrant. After obtaining the candidates, reranking is performed using a Cross Encoder. If necessary, the results are expanded with data from the symbol index and the dependency graph. The final list must contain the most relevant definitions.

### Tools

- Qdrant
- Ollama
- Cross Encoder (by default: qllama/bce-reranker-base_v1)

### Input

A text query.

### Output

A sorted list of results.

### Acceptance criteria

- semantic search is performed;
- reranking is applied;
- the results are sorted by relevance;
- combining several data sources is supported.
