# Task 10. Implementing the MCP server

## Description

Implement an MCP server that provides tools for searching and analyzing code. The server must support the STDIO transport and publish a list of available tools with JSON Schema of parameters. Each tool must be implemented as an independent handler that uses the internal search services. The server must not contain indexing business logic, but only coordinate the calls to the corresponding modules.

### Tools

- Model Context Protocol SDK (for JVM or a compatible protocol implementation)
- JSON-RPC
- Clojure

### Input

JSON-RPC requests from the MCP client.

### Output

JSON-RPC responses.

### Acceptance criteria

- the server starts correctly;
- it publishes the list of tools;
- it accepts requests;
- it returns correct responses;
- it supports several sequential requests.
