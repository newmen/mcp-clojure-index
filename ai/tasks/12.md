# Task 12. Integration with Kilo Code

## Description

Connect the MCP server to Kilo Code as a local tool. After launch, the agent must automatically discover the published tools and use them when working on the project. The correctness of passing arguments and handling responses must be checked. The integration must work without changing the Kilo Code source code.

### Tools

- Kilo Code
- MCP

### Input

MCP configuration in Kilo Code.

### Output

A working local MCP server available to the agent.

### Acceptance criteria

- the server connects successfully;
- the tools are shown in Kilo Code;
- the tools are called automatically;
- the results are used by the agent.
