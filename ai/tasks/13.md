# Task 13. Testing and optimization

## Description

Perform comprehensive testing of all system components, verifying the correctness of indexing large projects, resilience to syntax errors, search performance, and incremental reindexing speed. Special attention should be given to the quality of semantic search and the accuracy of reranking. Based on the test results, eliminate bottlenecks and optimize memory and compute usage.

### Tools

- clojure.test
- Kaocha
- criterium

### Input

A set of test projects and queries.

### Output

A test report and an optimized system.

### Acceptance criteria

- all tests pass successfully;
- performance meets the required parameters;
- no memory leaks;
- search results are stable and reproducible.
