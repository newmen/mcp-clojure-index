# Task 15. Per-project embedding cache

## Description

Move the embedding cache from the MCP server project root into the root of the indexed project, so that different projects do not collide on chunk hashes.

## Details

### The current problem

The embedding cache is stored in `.mcp/embedding-cache` relative to the MCP server's `workingDirectory` (i.e. `/Users/mcp/.mcp/embedding-cache`). When indexing another project, chunk hashes may match the hashes of the first project's chunks, which leads to:
- using incorrect cached embeddings;
- being unable to clear the cache per-project;
- confusion when working with several projects in parallel.

### Solution

The embedding cache should be located **inside the indexed project**: `<root-path>/.mcp/embedding-cache`.

### 1. The `:embedding/cache-dir` rule in `resolve-config`

Already described in task 14, but must be explicitly tested:

1. Explicit in `config.edn` → used as is (for tests and special cases)
2. `(str root-path "/.mcp/embedding-cache")` — by default

### 2. Changes in `mcp.embeddings`

The `cache-dir` function already uses `(:embedding/cache-dir cfg)` — it does not need to be changed, since `resolve-config` already substitutes the correct path.

### 3. Add `.mcp/` to the standard exclude lists

`.mcp/` is already present in `:index/exclude` as `".mcp"`. Make sure the watcher and the parser do not try to index files from `.mcp/`.

### 4. Tests

Add tests to the corresponding modules:

**`test/mcp/config_test.clj`:**
- `resolve-config-cache-dir-uses-root-path` — cache-dir is computed as `<root-path>/.mcp/embedding-cache`
- `resolve-config-cache-dir-explicit-override` — the explicit cache-dir in config.edn overrides the computed value

**`test/mcp/embeddings_test.clj`:**
- `cache-dir-default-is-in-root-path` — the default cache-dir is inside the root-path
- `cache-embedding-roundtrip` — the full cycle: write → read the cache

**`test/mcp/watcher_test.clj`:**
- `should-watch-excludes-mcp-dir` — the `.mcp/` directory is excluded from watching

### Acceptance criteria

- [ ] `:embedding/cache-dir` is computed by default as `<root-path>/.mcp/embedding-cache`
- [ ] An explicit `:embedding/cache-dir` in `config.edn` overrides the value
- [ ] `.mcp/` is excluded from indexing and watching (already in the defaults — verify)
- [ ] The embedding cache for each project is stored separately
- [ ] All tests pass (0 failures, 0 errors)
